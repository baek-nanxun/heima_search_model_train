# 招聘实体抽取与分类提示词确认稿

> 状态：已确认，可进入 Pilot 标注  
> 提示词版本：`recruitment_label_prompts_v2`  
> 生成入口：`python code/scripts/02_data_label.py prompts`

## 需要确认的关键口径

1. “短期工、假期工、学生工”等属于**用工类型分类**，输入来自 `employmentType`；`workMode` 仅表示现场办公、远程办公、线上线下结合。
2. 实体抽取与实体分类拆成独立任务，抽取输出不混入标准分类标签。
3. 岗位名称分类金标优先使用源数据可靠路径；路径缺失时，将完整一级-二级-三级岗位候选注入 Gemini 标签生产提示词，候选不写入微调训练语料。
4. 重名三级职位不生成“三级名称到父类”的关系样本；二级子类枚举输入使用一级/二级完整路径。
5. 工作场所候选使用“一级分类-二级分类”扁平列表；福利分类只使用标准福利词，不输出福利维度。
6. 除 `position[1]` 和标准化 `workMode` 外，抽取值必须逐字来自输入；未通过校验的样本进入审核队列。
7. 正式训练混入 5%–15% 有合法来源的通用指令回放数据；通用任务沿用其原始提示词和自然语言输出，不强制 JSON，也不由本标注脚本伪造。

## 语料类型

| 类型 | task | 输入 | 输出 | 金标来源/质量门 |
| --- | --- | --- | --- | --- |
| 实体抽取 | `entity_extraction` | 职位展示文本或用户搜索词 | 16 字段实体 JSON | Gemini 辅助标注 + 原文可定位校验 |
| 岗位名称分类 | `job_name_classification` | 岗位实体 + 必要上下文 | 一级/二级/三级职位 | 源路径优先；缺失时 Gemini 从完整候选中选择 |
| 三级职位父类推理 | `taxonomy_leaf_to_parent` | 唯一三级职位名 | 二级/一级父类 | 标准岗位分类数据确定性生成 |

## 训练与评估组合建议

- 招聘领域 SFT：约 85%–95%，覆盖上表九类招聘任务。
- 通用能力回放：约 5%–15%，保持原任务提示词与回答风格，避免模型形成“任何问题都输出招聘 JSON”的偏置。
- 负样本：实体抽取包含全空输出样本；闭集分类包含真正无法判断的“其他”样本，但不能为了凑比例误标。
- 冻结评估集：按源记录与近重复簇隔离，建议 100% 人工审核，不参与训练和提示词调优。

### `entity_extraction`

```text
你是招聘文本实体抽取标注专家。仅在本任务中返回一个 JSON 对象，不输出解释、Markdown 或额外字段。

输出 JSON schema：
{"position":[],"company":"","location":"","workPlace":"","workMode":"","salary":"","salaryPayment":"","employmentType":"","schedule":[],"description":[],"responsibilities":[],"requirements":[],"preferredQualifications":[],"education":"","workExperience":"","benefits":[]}

标注规则：
1. position 最多两个元素。position[0] 是原文中最具体、最原始的岗位名称；position[1] 是基于 position[0] 归纳的源语言通用岗位名，不得翻译或改变核心含义。
2. company 是招聘公司、门店或机构名称；location 是城市、区县、街道或商圈等行政地理信息；workPlace 是具体场所、机构、建筑、门店、仓库、工地等名称。
3. workMode 只能是“现场办公”“远程办公”“线上线下结合”之一；未明确提及则为空字符串。
4. salary 只抽取明确薪资范围或金额；salaryPayment 只抽取明确结算周期或方式；employmentType 抽取全职、兼职、临时工、实习生等用工类型原文。
5. schedule 抽取具体工作时段、班制和休息安排；description 只放岗位、团队或公司的背景描述，排除职责、要求和福利。
6. responsibilities、requirements、preferredQualifications、benefits 每项使用原文中的简洁关键词或短语，不输出改写后的整句。
7. 除 position[1] 和标准化 workMode 外，所有非空值都必须逐字来自输入。
8. 未出现字段使用空字符串或空数组。禁止输出岗位类目、用工类型类别、场所类别、结算类别、时间类别或福利类别。
```
